# 操作ガイド

通常起動の操作ガイドです。画面の操作例と、自分のデータを保存・分析する操作を区別して進めます。起動・Codex接続は [README](../README.md)、保存先・移行・APIは [共通の好みとプロジェクト](projects.md) を参照してください。

## 手動で設計を保存する

1. `npm run dev` またはビルド済みアプリを起動し、ブラウザで開きます。初回は起動ターミナルの接続コードを入力し、プロジェクト一覧へ進みます。
2. 「自分の好み」で14問の比較・理由・採用する原則を記録し、「共通の好みを保存」で確定します。未回答は未確認として残ります。具体的な色やpx値は自動生成されません。
3. 「プロジェクト」から名前を入力して作成します。「共通の好みを使う」の選択と参照版を確認します。既存プロジェクトには共通更新が自動で適用されず、概要の「差分を確認」で取り込み／維持を選びます。
4. Foundationで色・文字・余白・角丸などを編集します。分類はクリックまたは左右矢印で切り替え、Home/Endで先頭／末尾へ進めます。Tabで選択中の分類と内容へ進めます。「変更を保存」で設計revisionを確定し、「未保存の変更を取り消す」で確定版へ戻せます。
5. Components / Patternsの設定や操作例、Previewの一覧・設定・フォーム、表示幅・検索・フィルタ・Dialogを確認します。Previewの角丸・余白の変更も保存バーから確定できます。画面内のサンプル操作は設計を試すためのものです。
6. Exportで確定revisionのDESIGN.md / JSON / CSS、またはDTCG・React・3画面PNGを含む一括ZIPを生成します。未保存の値と未採用候補は出力に含みません。PNG生成に失敗したら再試行か「画像なし ZIP」を選べます。過去Exportも履歴から取得できます。

## 参考とAIを明示的に使う

共通の参考は「自分の好み」、プロジェクト固有の参考はInspirationに保存します。公開HTTP(S) URLを追加すると撮影ジョブが始まります。取得できない場合は、同じ参考の「画像で続行」から10MB以下・2500万画素までのPNG / JPEG / WebPを追加できます。

観点とメモを保存し、画面の送信対象を確認して「Codexで分析する」を押します。分析結果は内容・根拠を確認して「設計方針として採用」を選びます。共通の原則に採用した場合は、さらに「共通の好みを保存」で確定します。参考の採用だけでFoundationの数値は変更されません。

設計を保存した後、対話パネルから提案を依頼できます。候補は仮Previewへ反映されます。「採用する」で新revisionに確定し、「見送る」で候補を閉じます。AI Reviewは保存済みrevisionの3画面を撮影し、機械検証とAIの指摘・根拠を表示します。修正案の仮Previewを確認し、「まとめて適用」で明示的に確定します。未保存の設計がある場合は、修正案を適用する前にFoundationで保存／取消を確認します。

通常起動の分析・提案依頼・AI ReviewはCodex接続を使い、画面に示す画像・設定・メモなどをOpenAIへ送信します。自動テストはMock AIと一時SQLiteを使用し、実Codexを呼びません。

## 保存と回復

確定版・履歴・画像・ジョブはスコープ別のSQLite／assetsに保存します。有効な未保存の編集はスコープ別のブラウザ下書きです。共通とプロジェクト、異なるプロジェクトの保存先は分かれています。

設計・好み・プロジェクト入力・参考メモの下書きを読み取れない場合は、未読データへの自動書込と対象の編集を止めます。「下書きを再読込」で取り戻すか、表示中の内容で置き換える操作を明示的に選んでから編集を続けます。残したい下書きがある場合は再読込を選びます。設計・好み・概要・参考メモの古い基準版の下書きは保持され、最新内容を確認するまで上書き保存できません。対話リクエストの読込に失敗した場合も保存データを保持し、再読込か新しい内容の入力を選べます。

保存が失敗したら入力と確定版を確認して再試行します。更新が確定した後の一覧・レビュー読込だけが失敗した場合は、表示される再取得操作で読む処理だけを再試行できます。待機／処理中の参考ジョブは「中断する」で停止できます。起動のやり直しで中断されたジョブは自動再実行されません。

参考の更新応答を待つ間に、別の操作による新しい保存内容を取得した場合は、その新しい表示を保持します。手元のメモが古い基準版に属する場合は入力を残して競合を表示します。「最新の保存内容を読み込む」で確認し、必要なメモを再入力してから保存してください。
