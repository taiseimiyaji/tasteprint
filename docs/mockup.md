# モックアップ操作ガイド

> Issue #9以降、共通の好みとプロジェクトの保存先・ルートを分離しています。現行の操作・API・移行手順は [projects.md](projects.md) を参照してください。以下の旧グローバルAPI・localStorageの記述は移行前の説明です。
初期画面はFoundationです。画面内のMock modeは、AIを呼ばず定型の提案で動作していることを表します。

1. InspirationでURLを追加するか、2MB以下のPNG / JPEG / WebPを追加します。参考にしたい観点を選びます。URLの自動取得は行いません。
2. Tasteで14問のA/B比較を試します。前の比較へ戻って回答を変更できます。
3. Foundationで色・文字・余白・角丸・境界線・影を変え、下の一覧を確認します。
4. 右のパネルで「角丸をもう少し弱くしたい」などを押すと、定型の提案がPreviewへ仮反映されます。採用・見送りを選べます。
5. Previewで一覧、設定、フォームと表示幅を切り替えます。検索と状態フィルタ、New project、フォーム送信も試せます。
6. ComponentsではDialogの開閉など、部品の操作を試せます。Patternsでは6種の構成例を選べます。
7. AI Reviewで簡易チェックを行い、Exportで現在の設定をMarkdown / JSON / CSSとして保存します。

設定、参照、Taste回答は同じoriginのブラウザに保存します。履歴の取り消しは現在のページセッション中のみです。サーバーには保存しません。画像で保存容量を超えた場合はヘッダーにエラーを表示するので、不要な画像を削除してください。

モックは単一ワークスペースです。Codex認証・SQLite・ジョブ・URL取得・Tunnel・DTCG・ZIPなどの本実装はSPECに残しています。レイアウト確認用の参考図は実際のサイトのスクリーンショットではありません。
